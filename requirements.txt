# ==========================
# INSTALLATION INSTRUCTIONS
# ==========================

# 1. Install Node.js 16+ and .NET 6 SDK
# 2. Install MySQL 8.0+ and create databases using /database/*.sql
# 3. Build the CEF UI:
#       cd src_cef && npm install && npm run build
# 4. Build the client scripts:
#       cd src_client && npm install && npx webpack
# 5. Build the .NET server:
#       cd dotnet/resources && dotnet restore && dotnet build
# 6. Configure /conf.json with your server settings
# 7. Configure /settings/ files (database connection, etc.)
# 8. Start RAGE:MP server
